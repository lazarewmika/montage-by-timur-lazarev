# Montage by Timur Lazarev

Монтаж вертикальных роликов (Reels, Shorts, TikTok) через Claude Code или Codex на вашем компьютере.

**Автор:** Timur Lazarev · Telegram [@Timurlaz](https://t.me/Timurlaz)

## Установка

Установка идёт через файл `INSTALL.md`, который вы получаете у автора. Прикрепите его в чат Claude (вкладка Code) и напишите «установи».
